MiniOS for a Study Room | C11 Phase 2 prototype
One simulated CPU | quantum=2 | payload budget=65536 bytes
Type help for commands. Notes persist; task state starts fresh on restart.
minios> task create Reading 4 256
Created P1 Reading: READY, burst=4, payload=256 bytes
minios> task create Quiz 2 128
Created P2 Quiz: READY, burst=2, payload=128 bytes
minios> block 1
OK: block 1
minios> step
[0,2) P2 Quiz         RUNNING -> FINISHED remaining=0
minios> tasks

minios> wake 1
